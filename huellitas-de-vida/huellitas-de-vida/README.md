# Huellitas de Vida – Clínica veterinaria

Sitio web basado en la estructura de la plantilla MediCloud (Vite).

## Estructura

```
src/
  index.html
  assets/
    images/   → imágenes (.jpg, .jpeg, .png)
    media/    → video y música
    js/       → main.js
    scss/     → style.scss
```

## Uso local

```bash
npm install
npm run dev
```

## Publicar en Netlify

- Build command: `npm run build`
- Publish directory: `dist`
